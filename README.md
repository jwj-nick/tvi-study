# TVI 탐구 가이드

여행 실질 가치 지수(TVI) 프로젝트를 **준비하며 공부하는 학습용 앱**입니다. 100만원으로 5개국(스페인·일본·미국·영국·중국)에서 며칠 지낼 수 있는지를 나타내는 지수를 만들고, 20년치를 계산해 실제 여행객 수와 비교하는 고등학교 AI 융합 탐구 프로젝트입니다.

> **이름 구분:** 이 앱은 「TVI 탐구 가이드」입니다. 10월 7일에 출품할 결과물 앱(지수 계산기·20년 그래프·검증 화면)과는 별개의 앱이며, 결과물 앱은 워크스페이스의 `70_TVI_APP/`에서 따로 만듭니다.

Live: https://jwj-nick.github.io/tvi-study/

## 구성

| 탭 | 내용 |

| **따라하기** | 재료 네 가지(Numbeo 물가 · ECOS 환율 · World Bank CPI · 데이터랩 여행객 수)를 모으는 단계별 안내 — 누를 메뉴, 붙여 넣을 주소·명령(복사 버튼), 주의 상자, 체크리스트 |
| **10/7까지** | 5분 브리핑 · 일곱 단계 한눈에(날짜·끝난 신호) · 단계별 할 일과 방법(Claude에게 부탁할 말 포함) · 버리는 순서 · 도구 상자 A~D |

## 원칙

- **퀴즈와 예시에 실제 환율·물가·통계 수치를 넣지 않습니다.** 계산 예시는 전부 가상 값이며 그렇게 표시합니다. 진짜 데이터는 출처에서 직접, 조회 날짜와 함께 수집합니다.
- 스스로 발견해야 할 내용(데이터의 한계 등)은 스포일러로 잠가 두었습니다.
- 따라하기 탭의 사이트 메뉴·통계표 코드·파일 구조는 2026-09-25에 직접 확인한 것만 적었습니다. 사이트가 바뀌면 다시 확인합니다.

## 구조

- `questions.js` — 퀴즈 36문항
- `app.js` — 렌더링·라우팅·퀴즈 엔진
- `style.css` / `index.html`
