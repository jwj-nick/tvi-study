# TVI 탐구 가이드

**Travel Value Index** — 100만원으로 5개국(스페인·일본·미국·영국·중국)에서 며칠 지낼 수 있는지를 나타내는 지수를 만들고, 20년치를 계산해 실제 여행객 수와 비교하는 고등학교 AI 융합 탐구 프로젝트의 학습 가이드입니다.

Live: https://jwj-nick.github.io/tvi-study/

## 구성

| 탭 | 내용 |
|---|---|
| 홈 | 시작 질문 · TVI 공식 머신(가상 예시 슬라이더) · 연구 질문 · 5개국 · 전체 일정 |
| 발표 | 중간발표(8/26) 슬라이드 8장 지도 · 준비 체크리스트 · 리허설 |
| 컴퓨터 | 폴더·경로·확장자·터미널·git·AI 환각 — 비유 먼저, 정의 나중 |
| 경제 | 환율·CPI·지수·명목/실질·TVI 식 해부 |
| 데이터 | 4개 출처 · 손 vs 자동 판단 · raw/processed · 발견 미션(스포일러 잠금) |
| 퀴즈 | 36문항 — 경제 / 컴퓨터·기술 / 발표 대비 / 복습 세트 |

## 원칙

- **퀴즈와 예시에 실제 환율·물가·통계 수치를 넣지 않습니다.** 계산 예시는 전부 가상 값이며 그렇게 표시합니다. 진짜 데이터는 출처에서 직접, 조회 날짜와 함께 수집합니다.
- 스스로 발견해야 할 내용(데이터의 한계 등)은 스포일러로 잠가 두었습니다.

## 구조

바닐라 HTML/CSS/JS, 빌드 없음.

- `content.js` — 학습 콘텐츠 데이터 (학습 진행 시 이 파일만 갱신)
- `questions.js` — 퀴즈 36문항
- `app.js` — 렌더링·라우팅·퀴즈 엔진
- `style.css` / `index.html`
