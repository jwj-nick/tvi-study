# TVI 탐구 가이드

여행 실질 가치 지수(TVI) 탐구를 **처음부터 끝까지 이해하고, 발표를 준비하고, 실제 여행에 써먹는 학습용 앱**입니다. 100만원으로 5개국(스페인·일본·미국·영국·중국)에서 며칠 지낼 수 있는지를 나타내는 지수를 만들고, 20년치를 계산해 실제 여행객 수와 비교한 고등학교 AI 융합 탐구 프로젝트입니다.

> **이름 구분:** 이 앱은 「TVI 탐구 가이드」입니다. 출품한 결과물 앱(오늘 환율 · 여행 예산 · 20년 분석)은 따로 있습니다: https://jwj-nick.github.io/high1/tvi/ (발표 슬라이드 `slides.html`, 발표 연습 `present.html`도 그 옆에 있습니다).

Live: https://jwj-nick.github.io/tvi-study/

## 구성 (2026-10-04 최종판)

| 탭 | 내용 |
|---|---|
| 홈 | 최종 결과 세 줄(출처 포함) · 결과물 앱 · 슬라이드 링크 · 가이드 지도 |
| 앱 뜯어보기 | 데이터 흐름 4단계 · 스크립트 11개(무엇을 · 왜 · 핵심 한 줄 · 체크 질문) · 화면 6개 · 이렇게 만든 이유 |
| 교훈 | 탐구하는 법 9장(AI가 실제로 한 실수 4가지 포함) · 내 말로 적기 |
| 여행에 쓰기 | 후보 비교 → 예산 → 관광지 예약 확인 → 환율 상식 → 내 TVI · 조사 에이전트로 새 도시 추가 |
| 발표 | 슬라이드 미리 보기 · 7장 목표 · 리허설 체크 · 예상 질문 내 답 |
| 경제 · 컴퓨터 · 데이터 | 개념 카드 |
| 퀴즈 | 46문항 — 최종 결과 / 경제 / 컴퓨터·기술 / 발표 대비 / 복습 |
| 지나온 길 | 8/10~10/7 타임라인(정한 것 · 이유 · 나중에 보니) · 준비하던 때의 탭(처음 홈 · 따라하기 · 10/7까지 · 8월 발표 · 8월 할일 · 설계 · 다른안) · 다음 탐구 아이디어 |

## 원칙

- **개념 카드와 퀴즈의 계산 예시는 가상 값입니다.** 진짜 데이터는 출처에서 직접, 조회 날짜와 함께 수집합니다.
- **예외: 결과 · 회고 부분**(홈의 최종 결과, 지나온 길, 교훈, 퀴즈 '최종 결과' 세트)은 실제 탐구 결과를 쓰고, 숫자마다 출처(결과 보고서 · 기사 원문)를 붙입니다.
- 링크는 탭 이름(`#home` 등)이나 https 주소만 씁니다. 페이지 안 앵커(`#abc`)는 해시 라우터가 탭으로 오인합니다.
- 학교 이름 · 학생 이름은 넣지 않습니다. 직접 적는 칸(교훈 · 예상 질문 답 · 체크)은 그 기기에만 저장됩니다.

## 구조

바닐라 HTML/CSS/JS, 빌드 없음.

- `final.js` — 최종판 콘텐츠(홈 · 앱 뜯어보기 · 교훈 · 여행 · 발표 · 지나온 길)
- `content.js` — 준비하며 공부하던 콘텐츠(개념 · 따라하기 · 8~9월 탭)
- `questions.js` — 퀴즈 46문항
- `app.js` — 렌더링 · 라우팅 · 퀴즈 엔진
- `style.css` / `index.html`
- `_check/verify.js` · `_check/render.js` — 배포 전 검사(`node _check/verify.js && node _check/render.js`)
