# 배포 전 검증 스크립트

브라우저로 눈으로 확인하기 어려울 때, 내용과 렌더 결과를 대신 검사한다.

```
node _check/verify.js    # content.js 구조 — 필드 누락, id 중복, URL 형식, 대본 길이 대비 목표 시간
node _check/render.js    # app.js를 최소 DOM 스텁으로 실제 실행 — 뷰별 HTML 검사
```

두 스크립트 모두 경로가 `C:/Kids/71_High_Projects/2608_TVI_app/`로 하드코딩돼 있다. 폴더를 옮기면 파일 맨 위 `dir` 값을 고칠 것.

## 무엇을 잡는가

- `content.js`에 필드를 빼먹었을 때 (렌더 결과에 `undefined`가 찍힌다)
- 체크박스·입력란 id가 겹칠 때 (localStorage 키가 충돌한다)
- 탭 이름이 아닌 앵커(`href="#nb"` 같은)를 넣었을 때 — **해시 라우터가 홈으로 튕긴다**
- 데드라인(8/26) 외의 날짜·요일이 콘텐츠에 섞여 들어왔을 때
- 예시 발표에 실제 가격처럼 보이는 수치가 들어갔을 때
- 대본 길이와 장별 목표 시간이 어긋날 때

## 무엇을 못 잡는가

레이아웃, 색, 폰트, 실제 클릭 동작. 이건 브라우저로 봐야 한다.
